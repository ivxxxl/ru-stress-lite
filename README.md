# ru-stress-lite

**Ударения в русском тексте за микросекунды и 12 МБ памяти.** Словарь на 3,2 млн словоформ в SQLite + фикс ударений для [Piper TTS](https://github.com/rhasspy/piper).

```
$ rustress "Мой дядя самых честных правил, когда не в шутку занемог"
Мой д+ядя с+амых честн+ых пр+авил, когд+а не в ш+утку занем+ог
```

## Зачем

Синтезаторы речи на русском путают ударения: Piper (через espeak) читает «з**а**мок» вместо «зам**о**к», «орг**а**нов» вместо «**о**рганов» — и при этом игнорирует знаки ударения в тексте. Нейросетевые расстановщики ударений решают это, но тянут за собой модели и словари в оперативной памяти: на нашем сервере такой занимал **2,2–2,5 ГБ** и падал по нехватке памяти.

ru-stress-lite делает основную часть работы почти бесплатно: словарь лежит на диске в SQLite, каждое слово — один запрос по ключу.

| | ru-stress-lite |
|---|---|
| Память процесса | ~12 МБ |
| Скорость | ~220 000 слов/с (один поток) |
| Словарь | 3,19 млн словоформ, 160 МБ на диске |
| Зависимости | только стандартная библиотека Python |

## Установка

```bash
pip install git+https://github.com/ivxxxl/ru-stress-lite
rustress-build          # скачает словарь RUAccent (~21 МБ) и соберёт базу в ~/.cache/rustress/
```

## Использование

```python
from rustress import Stressor, stress

stress("Арифметическим квадратным корнем называется неотрицательное число")
# 'Арифмет+ическим квадр+атным к+орнем назыв+ается неотриц+ательное числ+о'

s = Stressor(mark="acute")          # знак ударения над гласной
s.stress("Замок на холме")          # 'За́мок на холме́'

s = Stressor(omographs={"замок": "зам+ок"})   # свой выбор для омографов
```

Командная строка: `rustress "текст"`, `echo текст | rustress --acute`.

### Piper TTS

espeak игнорирует ударения в тексте, поэтому ставим их прямо в звуки: ударной гласной — полное звучание, бывшей ударной — редукцию, как в живой речи. Предлоги и частицы остаются безударными (фраза идёт в espeak целиком).

```python
from piper import PiperVoice
from rustress import Stressor
from rustress.piper import phonemes

voice = PiperVoice.load("ru_RU-irina-medium.onnx")
ids = voice.phonemes_to_ids(phonemes(voice, "Замок стоит на холме.", Stressor()))
audio = voice.phoneme_ids_to_audio(ids)
```

Полный пример — [`examples/piper_demo.py`](examples/piper_demo.py).

## Ограничения (честно)

- **Омографы** (з**а**мок / зам**о**к, ст**о**ит / сто**и**т) без смысла фразы не различить. Для самых частых есть список вероятного варианта (`OMOGRAPHS`) — дополняйте своим. Если нужен контекст, берите нейросетевые решения, например [RUAccent](https://github.com/Den4ikAI/ruaccent).
- Ошибки словаря переходят как есть (например, «честн+ых»). Исправления — через `omographs={...}`.
- Односложные слова и слова с «ё» не размечаются — там ударение и так однозначно.
- Числа и сокращения не размечаются.
